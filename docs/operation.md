# 操作說明

給員工與主管。不需要任何技術背景，用瀏覽器打開網站即可。

左側導覽列可以切換「問答、試算、條文與函釋、資料狀態」四個頁面。

## 💬 問答：有問題直接問

1. 在畫面最下方的輸入框打字提問，按 Enter 送出；剛打開時也可以直接點範例問題
2. 回答會先給結論，再列重點；每個重點後面的【勞動基準法 第 38 條】是出處
3. 點「📎 引用條文」可以看條文原文，點「原文」會連到全國法規資料庫

**好的問法**：像問同事一樣，把情況說清楚

- ✅「我去年 3 月到職，現在可以放幾天特休？」
- ✅「媽媽住院需要照顧，可以請什麼假？薪水怎麼算？」
- ✅「主管叫我加班只能換補休，我可以要求領加班費嗎？」
- ❌「特休」（太短，不知道想問什麼）

**可以追問**：例如先問「平日加班費怎麼算？」，再問「那休息日呢？」。系統會參考**最近 2 題**，並在回答下方顯示它把問題理解成什麼（「已依對話脈絡將問題理解為…」），理解錯了可以直接把問題寫完整重問。換主題時請按左側的「🆕 新對話」。重新整理頁面會清空對話。

**請勿輸入個人資料**：身分證字號、手機、Email 會被自動遮蔽，但姓名、薪資明細等無法自動辨識，請不要輸入。

**看到這些字眼時**

| 回答中出現 | 意思 |
|---|---|
| 「找不到可以回答這個問題的條文」 | 系統收錄的規章與法規裡沒有相關規定，**不是故障**，請直接詢問人資 |
| 「此條工作規則可能違反法令」 | 公司規章比法律規定更不利於員工。請人資確認，依法應以法律規定為準 |
| 「請使用 🧮 試算」 | 這個問題需要精確計算，請到試算分頁 |
| 「此點資料未直接規定，建議向人資確認」 | 系統先回答能確定的部分，這一點收錄的資料沒有明文規定 |
| 「我不太確定您指的是先前哪一個問題」 | 追問的對象超出最近 2 題，請把問題寫完整重問 |
| 「⏳ 已達…每分鐘使用上限，請約 N 秒後再試」 | 本 demo 使用 Google 免費方案，等待提示的秒數後再問即可 |
| 「🚫 今日的…免費額度已用完」 | 當天的免費額度用完，約台灣時間下午 3~4 點重置 |
| 「由備用模型回答」「改用關鍵字檢索」 | Google 服務忙碌或額度不足，系統已自動改用備援方案，回答仍可參考，但準確度可能略低 |

## 🧮 試算：算特休與加班費

- **特休**：選擇到職日與查詢日，會顯示目前可享有的天數，以及每一次取得特休的日期
- **加班費**：輸入月薪、選擇平日或休息日、輸入時數，會顯示每一段的倍率與金額

試算由程式依法條公式計算，不經過 AI，同樣的輸入一定得到同樣的結果。實際金額以公司核算為準（例如月薪是否包含其他津貼）。

## 📚 條文與函釋：自己翻原文

選擇法規或公司工作規則，可以用關鍵字篩選，例如輸入「特別休假」只顯示相關條文。

## 🗂️ 資料狀態

顯示收錄的法規與版本（修正日期）。法規每週自動檢查一次，有修正時會自動更新。
「最近執行紀錄」中出現「error」時，請通知系統負責人。

## 重要提醒

本系統的回答僅供參考，不構成法律意見。個案情況請以人資部門及主管機關的解釋為準。
